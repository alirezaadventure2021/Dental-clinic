# Website Redesign Plan: Dental Clinic

## Overview

Redesign the dental clinic website using design patterns from the awesome-design-md repo (Airbnb, Apple, Notion) while maintaining the existing gold-centric luxury aesthetic and RTL Persian layout.

## Design Analysis Summary

### From the Repo (Key Patterns to Adopt)

**Spacing System (Apple-inspired)**
- Base unit: 8px with 4px micro-step
- Section padding: 80px vertical (currently 96px - reduce for tighter rhythm)
- Card padding: 24px consistent
- Max content width: 1280px (currently 1280px - keep)

**Typography Hierarchy (Apple/Notion-inspired)**
- Display: 56px/600 with -1px letter-spacing (currently 72px - reduce for readability)
- Headings: 600 weight (currently 700 - soften)
- Body: 16px/1.55 (currently 16px/1.6 - tighten slightly)
- Letter-spacing: negative on display sizes for "tight" feel

**Component Patterns (Airbnb/Notion-inspired)**
- Buttons: 8px radius (currently 12px - soften)
- Cards: 12px radius with 1px hairline borders (currently 16px - adjust)
- Inputs: 8px radius, 44px height
- Badges: pill-shaped (9999px radius)

**Layout Patterns (Apple-inspired)**
- Alternating light/dark sections for rhythm
- Edge-to-edge hero with centered content
- 2-column layouts with sticky sidebars
- Generous whitespace between sections

**Motion Patterns (Current + Enhancements)**
- Scroll reveal with stagger (keep existing)
- Add: micro-interactions on buttons (scale 0.95 on press)
- Add: smooth section transitions
- Keep: reduced-motion support

## Implementation Plan

### 1. Update Design Tokens (`index.css`)

**Colors (keep gold palette, refine shades)**
```css
/* Keep existing gold palette, no changes needed */
--gold: #C6A962;
--gold-light: #D4BC7C;
--gold-dark: #A8903E;
```

**Typography (refine hierarchy)**
```css
/* Reduce display size, add letter-spacing */
--font-size-hero: 56px; /* was 72px */
--font-size-display-lg: 40px; /* was 48px */
--font-size-display-md: 32px; /* was 36px */

/* Add letter-spacing for display sizes */
--letter-spacing-tight: -1px;
--letter-spacing-normal: 0;
```

**Spacing (tighten rhythm)**
```css
--spacing-section: 80px; /* was 96px */
--spacing-card: 24px; /* keep */
--spacing-element: 16px; /* keep */
```

**Border Radius (soften)**
```css
--radius-button: 8px; /* was 12px */
--radius-card: 12px; /* was 16px */
--radius-input: 8px; /* was 12px */
--radius-pill: 9999px; /* keep for badges */
```

### 2. Update Component Styles

**Buttons**
- Reduce border-radius from 12px to 8px
- Add `transform: scale(0.95)` on active state
- Keep gold gradient hover effect

**Cards**
- Reduce border-radius from 16px to 12px
- Add 1px hairline border in light mode
- Keep glass morphism effect in dark mode

**Inputs**
- Reduce border-radius from 12px to 8px
- Set height to 44px
- Add focus ring with gold color

**Navigation**
- Keep existing glass morphism effect
- Reduce height from 80px to 64px (Apple-inspired)

### 3. Update Layout Rhythms

**Hero Section**
- Reduce padding from 96px to 80px vertical
- Reduce headline from 72px to 56px
- Add negative letter-spacing (-1px)

**Section Transitions**
- Keep alternating light/dark backgrounds
- Reduce vertical padding from 96px to 80px
- Add more whitespace between elements (24px → 32px)

**Grid Layouts**
- Keep existing 2-column layouts
- Reduce gap from 24px to 16px for tighter card grids
- Keep max-width at 1280px

### 4. Enhance Motion Patterns

**Micro-interactions**
```css
/* Button press effect */
.btn-primary:active {
  transform: scale(0.95);
  transition: transform 0.1s ease;
}

/* Card hover lift */
.card:hover {
  transform: translateY(-4px);
  transition: transform 0.2s ease;
}
```

**Section Reveals**
- Keep existing scroll reveal system
- Add stagger delays (80ms increments)
- Keep reduced-motion support

**Smooth Transitions**
- Add `transition: all 0.2s ease` to interactive elements
- Keep existing animation keyframes
